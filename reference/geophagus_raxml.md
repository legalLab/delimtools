# Geophagus Eartheaters Phylogram

This is a Maximum Likelihood Estimation Tree containing unique
haplotypes from [geophagus](geophagus.md) estimated using RAxML-NG v.
1.1.0-master. Unique haplotypes were select using
[hap_collapse](hap_collapse.md).

## Usage

``` r
geophagus_raxml
```

## Format

An object of class
[treedata](https://rdrr.io/pkg/tidytree/man/treedata-class.html).
