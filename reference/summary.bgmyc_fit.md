# Summary of a Bayesian GMYC (bGMYC) delimitation

Prints a summary of the MCMC run and species delimitation results from a
`bgmyc_fit` object.

## Usage

``` r
# S3 method for class 'bgmyc_fit'
summary(object, ...)
```

## Arguments

- object:

  An object of class `bgmyc_fit`, as returned by [`bgmyc()`](bgmyc.md)
  (or equivalent fitting function).

- ...:

  Additional arguments, currently ignored (included for S3 method
  consistency).

## Value

Invisibly returns `object`.
