# Geophagus Eartheaters Posterior Trees

This is a set of 100 ultrametric trees sampled from the posterior trees
used to estimate [geophagus_beast](geophagus_beast.md) using BEAST2
v2.6.7. Meant to be used for
[confidence_intervals](confidence_intervals.md) estimation.

## Usage

``` r
geophagus_posterior
```

## Format

An object of class
[multiphylo](https://rdrr.io/pkg/ape/man/multiphylo.html)
