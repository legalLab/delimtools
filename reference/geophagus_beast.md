# Geophagus Eartheaters Ultrametric Tree

This is a Maximum Clade Credibility (MCC) tree containing unique
haplotypes from [geophagus](geophagus.md) estimated using BEAST2 v2.6.7.
Unique haplotypes were select using [hap_collapse](hap_collapse.md).

## Usage

``` r
geophagus_beast
```

## Format

An object of class
[treedata](https://rdrr.io/pkg/tidytree/man/treedata-class.html).
