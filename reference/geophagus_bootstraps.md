# Geophagus Eartheaters Bootstrap Trees

This is a set of 100 Maximum Likelihood trees sampled from bootstrap
trees used to estimate [geophagus_raxml](geophagus_raxml.md) using
RAxML-NG v. 1.1.0-master. Meant to be used for
[confidence_intervals](confidence_intervals.md) estimation.

## Usage

``` r
geophagus_bootstraps
```

## Format

An object of class
[multiphylo](https://rdrr.io/pkg/ape/man/multiphylo.html)
